Activator/GameMode handles the script that runs locally in the cell. Basically, the following takes place during a typical Horde Mode Scenario:
1) the player enters the cell
2) the player interacts with the activator (can be anything, from a lever, button, or attunuator
3) the player is given 10 seconds to prepare and 3-5 scrolls that summon a unit or tower. summoning can take be done whenever, as players may wait to see where the
   the bulk of enemies spawn in and where
4) In future versions of this mod, a merchant will spawn in with sellable scrolls to summon towers and units

*This script does not handle the maps / locations of the mod, however it can be adjusted for different enemies via the Spawn script
